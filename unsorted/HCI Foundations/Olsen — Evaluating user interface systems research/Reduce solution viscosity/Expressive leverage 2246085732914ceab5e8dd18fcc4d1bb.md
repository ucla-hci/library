# Expressive leverage

Description: The ability to accomplish more by expressing less.
"... achieved when a tool reduces the total number of choices that a designer must make to express a desired solution."
How to claim/evaluate: 1. Eliminate repetitive choices by reuse (recurring decision can be made once as a global setting); generalizing certain tasks (creating any table amounts to specifying the # of rows and columns);
2. Imply more choices from existing ones (e.g., setting complementary colors once the background color is set);
3. Through the progress of technology (e.g., faster processor makes UI response optimization obsolete).
