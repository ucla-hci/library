# Corvo et al.: IIComPath — Visual Analytics for Hypothesis-Driven Exploration in Computational Pathology

## One Sentence
A 2021 IEEE TVCG system paper presenting IIComPath, a visual analytics tool that lets clinical researchers formulate imaging biomarker hypotheses and build computational pathology pipelines interactively.

## More Sentences
As computational pathology generates increasingly complex image-derived feature spaces, IIComPath provides interactive support for cohort construction, spatial analysis of cell-level image features, and cohort-level statistical analysis — all organized around researcher-defined hypotheses. Case studies demonstrate how the tool supports both validation of known prognostic features and exploration of novel imaging biomarkers for cancer diagnosis. The design explicitly positions hypothesis formulation as the entry point to each analysis session.

## Key Points

### Hypothesis-Centered Workflow Design
The system places hypothesis formulation at the head of the pipeline: researchers state what they expect to find before constructing cohorts or running spatial analyses.

### Domain: Biomarker Validation
IIComPath supports the validation of quantitative imaging biomarkers — a canonical hypothesis validation task in translational medicine — via interactive visual means.

### Case Study Validation
Two case studies examine prognostic value of known diagnostic features alongside novel biomarkers, demonstrating the tool supports both confirmatory and exploratory ends of the hypothesis cycle.

## Other Notes
Authors: Alberto Corvò, H.S. Garcia Caballero, Michel A. Westenberg, Marc A. van Driel, Jarke J. van Wijk. Published in IEEE Transactions on Visualization and Computer Graphics, Vol. 27, No. 10 (2021). Bridging HCI/VA and biomedical imaging. [abstract only]

## Take-Away
A domain-specific operationalization of hypothesis-driven analysis in a high-stakes scientific context (cancer research), showing how VA systems can structure the full hypothesis validation loop for domain scientists.
