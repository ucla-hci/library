### Spec is the primary artifact, code secondary
> ... prioritises communication first, with code as a secondary artifact. We describe our intentions and desired outcomes, letting the model handle implementation details. Yet paradoxically, we then discard the prompts--they very specifications that contain our intent--while carefully preserving the generated code.
